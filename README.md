# 🔒 SecureLocker Pro - Chain of Custody Evidence Management System

## 🇮🇳 Government of India | Ministry of Home Affairs | Kerala Police

A comprehensive digital evidence management platform designed for law enforcement agencies to maintain chain of custody integrity with cryptographic verification and real-time audit trails.

---

## 📋 Overview

SecureLocker Pro is a sophisticated web-based application that revolutionizes how law enforcement agencies manage digital evidence. It provides a secure, auditable, and user-friendly platform for handling sensitive case files, evidence documentation, and inter-departmental communication throughout the entire investigation process.

---

## 🚀 Features

### 🔐 Security & Integrity
- **AES-256 Encryption** for data protection
- **SHA-256 Cryptographic Hashing** for tamper detection
- **TLS/SSL** encrypted data transmission
- **Role-Based Access Control** with dual-permission system
- **Session Management** with automatic invalidation

### 📊 Audit & Compliance
- **Comprehensive Audit Trails** for every action
- **Chain of Custody Tracking** from collection to courtroom
- **Tamper-Evident Logging** for forensic validity
- **Court Admissible** evidence documentation

### 👥 User Features
- **Secure Registration** with professional verification
- **Admin Approval Workflow** for controlled access
- **Evidence Discovery** with metadata browsing
- **Access Request System** with justification tracking
- **In-Browser Evidence Preview** (images, videos, PDFs, documents)
- **Secure Chat** between users and administrators

### 🛠️ Admin Capabilities
- **Complete User Management** (approve, ban, unban)
- **Request Management** with toggle access controls
- **Case Management** (create, edit, lock, unlock, delete)
- **Evidence Management** (upload, verify, delete)
- **Real-Time System Monitoring** and activity logs
